## The context

Mariette is an independent professional who wanted **a blog she fully owns** — not Medium, not Substack — paired with a portfolio her prospects can browse frictionlessly. The constraint: she should write an article like she writes in Notion, without learning a new tool.

## The approach

Next.js 15 App Router for SSR + SEO, MongoDB for data, NextAuth v5 for admin. A **custom Tiptap editor** on admin, which is the only real hand-rolled piece in the project.

## Notable technical decisions

- **Next.js 15 + React 19 + TypeScript 5.7** on strict App Router — no leftover Pages Router.
- **MongoDB + Mongoose 8** — simple domain (Article, Tag, Comment, User), no Postgres needed.
- **NextAuth v5 (beta) + `@auth/mongodb-adapter`** — three active providers: Google OAuth, GitHub OAuth, credentials (server-side `bcryptjs`).
- **Tiptap 3** as editor — extensions: image (drag&drop UploadThing), link, table, text-align, highlight, color, underline, bubble menu, custom slash commands.
- **UploadThing 7** for media — typed server uploads, simpler than rolling S3 + signed URLs.
- **react-hook-form + Zod** on admin forms.
- **TanStack Query 5** for client-side admin lists and pagination.
- **Framer Motion 12** for transitions and scroll-reveal.
- **Nodemailer 7** for the contact form.
- **next-themes** for auto light/dark mode.
- **react-easy-crop + UploadThing** for profile pic and article cover cropping.
- **Sitemap + robots + manifest** generated by `app/sitemap.ts`, `app/robots.ts`, `app/manifest.ts`.
- **Admin scripts** in `tsx`: `seed:admin`, `check:admin`, `test:password`, `diagnose:auth` for prod debug.

## The editor — the piece we wrote twice

First version used `@tiptap/react` with default extensions. Mariette tripped on images: drag&drop didn't always work, resizing didn't exist.

Rewrite: a custom `ImageNode` extension that:
1. Accepts drag&drop, paste from clipboard, AND upload button
2. Background-uploads to UploadThing, shows a skeleton meanwhile
3. Allows handle-based resizing
4. Persists position as HTML attribute

Two weeks to get it right. But that's what makes the admin usable.

## What worked, what didn't

**Worked.** App Router. Once past the learning curve, the server / `'use client'` mix gives production performance no SPA framework reaches without equivalent effort.

**Didn't.** NextAuth v5 in beta — every minor update broke something. I pinned a stable version and stopped chasing updates.

## Take-away

For a personal blog + portfolio, **the editor is 80% of dev effort** — paradoxical, since it's the least publicly visible component. But it's what makes the owner write a post a week instead of one a quarter.

Investing time there always pays off.
