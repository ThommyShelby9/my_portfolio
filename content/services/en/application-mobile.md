In the field, the network is rarely perfect. An app that freezes when 3G drops will not be used. I design mobile apps for these real conditions first: fast start, offline mode, reliable sync.

## What I deliver

- **Flutter apps** for Android and iOS, with geolocation, camera, notifications and encrypted storage.
- **Capacitor apps** that reuse a Vue or React web app.
- **PWAs** installable from the browser, without the app stores.
- **Offline mode** and sync when the network returns.
- **Notifications**: Firebase Cloud Messaging on mobile, Web Push in the browser, SMS as a fallback.
- **The API** behind the app, designed at the same time.

## Apps already shipped

**Ubbfy**: the Flutter time-tracking app starts instantly thanks to cached site coordinates, and without network, the clock-in is stored encrypted, then synced when the connection returns.

**MonCarnet**: a family health record as a PWA, linked to the health centre, with community health workers’ rounds that work offline.

**ZenLife**: an everyday app on web and mobile, built with Capacitor and Spring Boot, designed and developed alone, which passed 1,200 active users in six months.

## Technologies

Flutter, Capacitor, PWA, React Native, Vue 3, Next.js, Firebase, Spring Boot, Django, encrypted local storage.
